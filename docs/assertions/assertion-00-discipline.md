Assertions are **laws**, not backlog wishes. Keep them few. Owner writes them; proofs go through tests / in-game checks when the project grows past hello-world.

**None beyond this discipline file is required** for a healthy v42.20-0.1 tree.

When an assertion is added, it must be checkable (console, file layout, or automated test).

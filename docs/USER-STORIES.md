A user story names a person and a want: *As a [role], I want [capability],
so that [value]*. Behavior lives in [[USE-CASES]]. Each story ends with
`Realized by`; the story is accepted when those cases pass.

## US-01 — Pick the detective fantasy

As a survivor creating a character, I want a **True Detective** profession with
clear stealth and urban-looting identity, so that I can play a meticulous
investigator without inventing house rules (and without relying on a third-party
simpler detective occupation).

Realized by: UC-01, UC-09, UC-10.

## US-02 — Loot urban clutter better

As True Detective, I want strong indoor/urban forage vision and junk/trash/ammo
affinity, so that cities and interiors reward careful searching more than
they do for generic combat professions.

Realized by: UC-02.

## US-03 — Investigate with the glass

As True Detective, I want to hold my magnifying glass for better search and
right-click Investigate on a quiet zombie or a corpse so I hear one
whispered mate or pack-origin lead — not aim at houses and channel a scan,
and not probe doors.

Realized by: UC-11, UC-12, UC-14, UC-15, UC-16, UC-18, UC-19.

## US-05 — Find a clue while walking

As True Detective, I want a chance to read footprints while I walk with the
glass, so that the street itself can give me a direction without another button.

Realized by: UC-17.

## US-04 — Enable the mod on my host

As a player or host on debian-sid Steam, I want a clear install path into
`~/Zomboid/mods` from `Contents/mods/TrueDetective` (or Workshop layout) for
B42.20 (`42.0/` version folder), so that the profession appears without
fighting B41 leftovers or ProfessionFactory-era docs.

Realized by: UC-10, UC-01.

# True Detective

**A Project Zomboid Build 42.20 profession mod.**

The city went quiet. You didn't.

Start every run as the **True Detective** — the occupation that walks into
the apocalypse already dressed for the case.

## What you get

- A **fedora**. Always.
- A **leather long coat**. Always.
- A **revolver** with spare rounds. Always.

No pistols. No raincoats. No excuses.

## Install

1. Subscribe on the
   [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3383387174)
   (or drop the folder into `Zomboid/mods`).
2. Main menu → **Mods** → enable **True Detective** → Apply.
3. New game → pick the **True Detective** occupation.

That's it. The coat does the talking.
